💡 Hur får jag tag på rapporterna?

  • 1. WP Systemrapport: Gå till Verktyg ➔ Hälsokontroll ➔ Info ➔ Kopiera info till en textfil.
  • 2. WooCommerce Status: Gå till WooCommerce ➔ Status ➔ Systemstatus ➔ Kopiera info till en textfil.
  • 3. Wordfence Diagnostik: Gå till Wordfence ➔ Verktyg ➔ Diagnostik ➔ Klicka på "Exportera" eller kopiera.
  • 4. Elementor Status: Gå till Elementor ➔ System Info ➔ Kopiera systeminfo till urklipp.
  • 5. Anpassad Kod: Kopiera din child-theme `functions.php` eller exporten från Code Snippets.
  • 6. LiteSpeed settings (.data): Gå till LiteSpeed ➔ Verktygslåda ➔ Import / Export ➔ Klicka på "Exportera" för att ladda ner nuvarande settingsfil (.data).

🏆 Guldstandarden för nysajter (Best Practice)

Det absolut snabbaste och säkraste sättet att konfigurera LiteSpeed Cache på en ny WooCommerce-butik är att kombinera LiteSpeeds förinställningar med vår app:

  1. Preset i WordPress: Aktivera först LiteSpeeds Advanced eller Aggressive förinställning under LiteSpeed Cache ➔ Presets i din WordPress-admin.
  2. Exportera settings: Ladda ner basinställningarna som en `.data`-fil under LiteSpeed Cache ➔ Verktygslåda ➔ Import / Export.
  3. Kör Säkerhetsaudit här: Ladda upp din `.data`-fil i **ruta 6** här i appen tillsammans med din WordPress-systemrapport, och starta analysen.
  4. Kirurgisk korrigering: Klicka på knappen \"Åtgärda alla avvikelser\" under fliken LSCWP Inställningar för att automatiskt injicera kassaexkluderingar och stabilitetsfilter.
  5. Ladda ner & Importera: Hämta den färdiga filen och läs in under Verktygslåda ➔ Import / Export för en e-handel som är både blixtsnabb och 100% driftsäker!
